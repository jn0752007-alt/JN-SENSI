JN SENSI - projeto Android base

Como compilar:
1. Extraia o ZIP.
2. Abra a pasta JN-SENSI no AndroidIDE (ou Android Studio).
3. Aguarde a sincronização do Gradle.
4. Execute Build > Assemble Debug.
5. O APK debug fica em app/build/outputs/apk/debug/app-debug.apk

Observações:
- Este projeto é um configurador de sugestões de sensibilidade.
- Não altera arquivos do Free Fire nem ativa hacks.
- Requer AndroidIDE/Android Studio e conexão para baixar componentes Gradle na primeira compilação.
